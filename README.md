**Hotel Oblívio** é uma interface web responsiva desenvolvida como projeto acadêmico para apresentação de um hotel fictício. O projeto permite explorar acomodações, selecionar períodos de hospedagem, organizar reservas e visualizar opções de pagamento em um ambiente totalmente demonstrativo.

## Funcionalidades principais

- Seleção de idiomas entre Português, Inglês e Espanhol
- Tradução nativa com persistência da preferência em `localStorage`
- Catálogo com três tipos de acomodação
- Seleção de datas de entrada e saída
- Validação automática das datas da estadia
- Cálculo automático do número de noites
- Carrinho lateral de reservas
- Contador de quartos selecionados
- Remoção de reservas e cálculo automático do valor total
- Modal de finalização da reserva
- Opções demonstrativas de pagamento:
  - Cartão de crédito
  - Pix
  - Boleto bancário
- Validação básica dos dados de pagamento
- Integração com o Google Maps
- Navegação responsiva para computadores, tablets e celulares
- Navegação ativa conforme a seção visível
- Menu mobile acessível
- Feedback visual por meio de mensagens e notificações
- Elementos semânticos, atributos ARIA e suporte à navegação por teclado

> Nota: Este projeto é hipotético e acadêmico. Nenhum dado financeiro é transmitido, armazenado ou utilizado para cobranças reais.

---

## Tecnologias utilizadas

- **HTML5** — Estrutura semântica das páginas
- **CSS3** — Estilização, responsividade e animações
- **JavaScript ES6+** — Interações e gerenciamento das reservas
- **Google Maps Embed API** — Exibição da localização
- **Unsplash** — Imagens das acomodações e do banner
- **LocalStorage** — Persistência da preferência de idioma

Não são necessários frameworks, gerenciadores de pacotes ou dependências externas.
