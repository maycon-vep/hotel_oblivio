# Hotel Oblívio

Site institucional para o Hotel Oblívio, criado para apresentar as acomodações, experiências e informações de contato do hotel. O projeto também conta com uma interface para consulta de disponibilidade e solicitação de reservas.

## Sobre o site

O site apresenta uma experiência responsiva e inclui:

- Apresentação do hotel e de suas acomodações;
- Informações sobre experiências, localização e contato;
- Mapa integrado ao Google Maps;
- Perguntas frequentes e informações sobre privacidade e LGPD;
- Interface para consultar datas e hóspedes e iniciar uma reserva;
- Opções de idioma em português, inglês e espanhol.

> A consulta de disponibilidade, o envio de mensagens e o fluxo de reserva são demonstrativos e funcionam no front-end. Para receber solicitações ou processar pagamentos de verdade, é necessário integrar um back-end e um serviço de pagamento.

## Linguagens e tecnologias

- **HTML5** — estrutura e conteúdo do site;
- **CSS3** — estilos, layout e responsividade;
- **JavaScript** — interações, seleção de idioma e fluxos demonstrativos de consulta e reserva.

O projeto também utiliza fontes do Google Fonts, imagens do Unsplash e mapa do Google Maps.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Para testar com recarregamento automático, você também pode abrir a pasta do projeto no VS Code e iniciar um servidor local, por exemplo, com a extensão Live Server.

## Estrutura do projeto

- `index.html` — estrutura das páginas e conteúdo;
- `css/style.css` — estilos e layout;
- `js/main.js` — interações do site;
- `assets/img/` — imagens e logotipo;
- `poo-reservas-hotel.js` — exemplo de gerenciamento de reservas usando Programação Orientada a Objetos em JavaScript.
